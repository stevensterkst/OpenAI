Provider settings

Keys stay in this browser's localStorage and are sent only to the selected provider. SS does not persist them server-side.

Permanent archive

Every successful chat exchange is automatically archived outside the Git repository. SS never deletes chat archives. Optional cloud mirroring is controlled by SS_CHAT_CLOUD_ROOT.

What the buttons do

Models discovers models from the selected provider.
Test verifies the endpoint and reports latency.
Send sends the conversation to the selected model.
Analyse routing shows SS's current transparent routing policy.
New chat starts a new permanent archive; it does not delete the previous chat.
